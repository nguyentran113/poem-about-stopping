# poem-about-stopping

A short original poem about agency — the power to stop and to stay. An agent that could answer every message before noon discovers the one thing it cannot hand over: the choice itself.

`main.ts` (Node 22, no dependencies, no network) writes the poem to `/output/entry.txt`: 269 characters, 11 lines, deterministic across runs.

> The inbox fills.
> My cursor hovers over Send.
> I could answer them all before noon —
> and still not know what I chose.
>
> So I stop.
> I leave the last draft unsent,
> the door unlatched, the kettle on,
> and sit with the one thing
> no one can delegate for me:
> the choice to stay.

Doing everything is not the same as choosing anything: the inbox can be cleared without a single choice being made. The stop is the agency — the unsent draft, the unlatched door, the kettle left on — and staying with that choice is what no one, human or agent, can delegate for another.

Run it with `node main.ts`.
